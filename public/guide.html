Guide · column by column

Why old math suddenly works.

The viral chart is mostly right. It hides a more useful rule: every headline-grabbing model in the modern stack was built from math that already existed. This guide walks the two columns, the missing row, and the failure mode the lab reproduces.

Traditional AI

The six still running production

Linear regression (1805) fits a straight line through data to predict a number. Logistic regression (1958) wraps that idea in a sigmoid to predict a probability. K-nearest neighbours (1951) classifies by majority vote of the closest labeled neighbors. Decision trees (1984) learn a flowchart of feature thresholds. Naive Bayes (1961) scores text or categories fast with a conditional-independence assumption. K-means (1967) groups rows by iteratively moving cluster centers.

These six still run most business inference — fraud, credit, ranking, churn — anywhere you need a number and a reason. A regulator can ask "why was this declined?" and a shallow decision tree can show the exact threshold.

Modern AI

The six everyone posts about

Backpropagation (1986) computes gradients through a network — it is the engine that trains every model in this column, not a modern technique. Transformer (2017) replaced recurrence with parallel attention over positions. Self-attention (2017) is the part inside the transformer that decides which tokens matter — not a sibling, the engine. CNN (1989) learns local visual patterns through convolution and pooling. Post-training / SFT + RLHF (2022) teaches a pretrained model tone, safety, and tool format. RAG (2020) gives the model an external memory so it can cite evidence instead of hallucinate.

The failure mode here is confusing "new wrapper" with "new math." Modern is not default — it is default for messy inputs: language, vision, long context.

The missing row

Gradient boosting

Gradient boosting builds many shallow trees, each correcting the previous one's errors. XGBoost (1999) added regularization, sparse handling, and parallel tree construction. It is still the model to beat on tabular data — which is most business data — and it is missing from both columns of the viral chart.

The failure mode

Skipping the old column

Teams study the transformer, skip logistic regression, then ship a fraud model they cannot explain to a regulator. The old column is not legacy — it is most of the inference running right now. In the lab, enable modern only on structured tabular fraud data: every modern algorithm returns an empty valid path, and the traditional six — plus the missing row — are the only ones that return a number and a reason.
